# Known Limitations

This document is intentionally blunt so the project's maturity is not overstated.

- No CPU instruction decoder or execution engine exists.
- No console GPU command processor or renderer exists.
- No guest operating-system or system-service implementation exists.
- No console-specific executable/package loader exists.
- No firmware, keys, game images, or commercial assets are included or supported by this scaffold.
- No commercial game compatibility is claimed.
- The memory bus is a generic tested utility, not a map of any real console.
- The current self-test validates only the project's own host-side foundation.

A successful build or self-test must never be described as proof that a game can boot.
