# LucidSwitch2 UI prototype

Open `index.html` in a modern browser. It contains a console-inspired home screen, game library, settings page, local file picker, and basic Gamepad API detection.

The prototype saves only filenames, extensions, and sizes in browser local storage. It does not upload or retain selected file bytes, validate console packages, decrypt content, or launch games. Imported entries are marked "Not launchable yet" intentionally.

This is a visual/interaction prototype, not the final native desktop UI. A native shell and a secure local file-provider API are still required.
